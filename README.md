# Python Hangman Game

## Project Description
A beginner-friendly Hangman word guessing game developed using Python.

## Features
- Three difficulty levels: Easy, Medium and Hard.
- Random word selection.
- Limited incorrect attempts.
- Displays correctly guessed letters.
- Interactive user input.

## Technologies Used
- Python
- Random module
- Loops
- Conditional statements
- Lists and strings

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python hangman.py
```
